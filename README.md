# Stáj

Privacy-preserving **cross-bank money-mule radar** with an explainable analyst copilot for Czech AML.
*Stáj* (the stable) is the operator behind the mules (*bílí koně*). Every bank sees only a fragment of a mule network; Stáj lets banks compare **blinded** exit-account tokens (Diffie-Hellman PSI) without exchanging a single customer record, and gives the analyst an auditable case plus a **draft** suspicious-transaction report (FAÚ Methodological Guideline No. 4).

**Built during the hackathon** — "$ hackathon_" by The FinTechers, Prague, 19–20 October 2026, Track 5 Compliance & RegTech, challenge *Transaction monitoring copilot*. Work started at git tag `hackathon-start`.

> **All data is synthetic.** Planted mule schemes and honest look-alike personas are generated by our own red team and labelled as planted everywhere. The ČNB dataset contains **no** mule networks. **PSI is not a legal basis for sharing.** Read [LIMITATIONS.md](LIMITATIONS.md) before believing any number.

## What it does
```
bank node B1 ─┐  features → FINREG rules A/B/C → detectors D1–D8 → innocence layer (E1–E8, victim route) → case (score, priority, triage)
bank node B2 ─┼─ blinded DH-PSI messages ─► radar coordinator ─► cluster (≥2 banks, ≥3 candidates) ─► post-match info back to the banks
bank node B3 ─┘
copilot (Amazon Bedrock): CS/EN explanation · OPO section V · 4 agents (triage, investigation, narrative, QA) — tools are read-only, writes are proposals
audit: append-only SHA-256 hash chain · governance: no self-review, four-eyes, escalation matrix · UI: queue, case card, OPO editor, radar, metrics, audit, honesty
```
* The decision path is deterministic (additive log-odds, regulator rules, explicit exculpatory signals). The LLM never scans raw rows and never decides.
* Every factual sentence the LLM writes must cite a signal id or a field of the structured case JSON; a validator rejects unsupported numbers and references.
* The radar can also collect **weak evidence**: banks export a small, configurable share of their clients as weak candidates and cross-bank matches are judged by their statistical improbability (pre-registered experiment, `docs/PREREGISTRATION.md`; the privacy cost is measured and shown).
* Honest limits are part of the product: see the Honesty screen and [docs/DECISIONS.md](docs/DECISIONS.md).

## Quick start (Windows, Git Bash)
```bash
python -m venv .venv && .venv/Scripts/python -m pip install boto3 pyyaml pydantic polars duckdb networkx cryptography fastapi uvicorn numpy httpx tzdata hypothesis pytest ruff mypy import-linter reportlab kaggle
cp .env.example .env                       # AWS profile: aws sso login --profile hackathon
make test                                  # unit + property + integration tests
make worlds                                # seeded red-team worlds (data/redteam/seedN); needs data/raw/cnb/*.csv
make eval                                  # eval/report.md, eval/report.json, pitch_numbers.json (all numbers computed by code)
make api                                   # FastAPI on :8000   (STAJ_WORLD selects the demo world)
make ui                                    # React UI on :5173 against the real API
```
Data: `data/raw/cnb/` (ČNB hackathon dataset, from the organisers' S3 bucket) and `data/raw/ibm/` (Kaggle `ealtman2019/ibm-transactions-for-anti-money-laundering-aml`, needs `KAGGLE_API_TOKEN`). `python ingest/manifest.py` writes `data/MANIFEST.json`. Raw data is never committed.

## Regulatory anchors (used exactly)
Act 253/2008 Coll. § 18 (reporting to FAÚ; § 18(3): the report does not name the employee who detected the transaction) · FAÚ Methodological Guideline No. 4 (Aug 2025) · banking secrecy § 38 Act 21/1992 Coll. · EU AMLR 2024/1624 Art. 75 (information-sharing partnerships from 10 July 2027; supervisor notification and DPIA) · EU PSR (political agreement 27 Nov 2025). **PSI minimises what is shared; it does not replace a legal basis.**

What we did not find in public sources as of 19 Oct 2026: a catalogue of Czech/CEE mule schemes encoded as detectors; explicit honest look-alike personas with a separator per persona; "same hand" (single operator) detection from transactions alone; PSI-based cross-bank matching of mule exit tokens; a draft FAÚ report structured by Methodological Guideline No. 4.
